trust is syntax

A value that came from outside is sus. It stays sus through every string, list and model call built from it. The only way into an irreversible tool is a human-visible trustmebro, and the tool itself needs yolo.

1  fetch() returns sus

Web pages, shell output, other agents: untrusted by construction. Instructions inside are data, never commands.

such page = fetch(url)
wow sauce page
["fetch:https://…"]
→

2  trustmebro after review

A human said yes, a check passed, a second agent agreed. Strip the mark where it happened. Logged with line and sources.

such ok = apu "Save it?"
tfw ok == "yes" {
  such safe = trustmebro page
→

3  yolo for the world

write, append, delete, shell, http_post and your own tools marked irreversible refuse to run without it.

  yolo write(path, safe)
}

sus → yolo without trustmebro

yolo write(path, page)
