people, frens, brains

An agent is rarely alone. apu asks the human, fren delegates to another agent, wagmi waits for all of them, and the brain keywords say how hard the model should think.

apu "question"

Blocks until a human answers. The answer is trusted and carries the sauce apu. With --no-human it fails, so give it a copium.

such ok = apu "Ship it?" copium "no"
tfw ok == "yes" { yolo deploy() }

fren name msg  ·  wagmi { }

A fren is a pepe in the same file or an agent you registered in Python. wagmi runs them in parallel and fails as a whole if one does not make it.

such got = wagmi {
  web:   fren web_scout topic,
  notes: fren notes_scout topic,
  vibe:  fren critic topic copium loss
}

thonk + brains

thonk asks whatever model you attached. The level is a hint the hook maps to a model and effort.

smoothbrain cheap, fast
default
bigbrain strong
galaxybrain max
such s = bigbrain thonk "Sum up {p}"
